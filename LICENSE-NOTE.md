# License — Not Yet Chosen

The maintainers have **not** selected an open-source license for this
repository. Per the master brief (§29 Step 3), a license must not be silently
adopted.

Until a license file is added, the following applies:

- **All rights reserved by the original authors.**
- No permission is granted to copy, modify, redistribute, or reuse this code
  in derivative works.
- Contributors submitting pull requests are asked to note their intent, since
  the licensing terms under which their contribution is accepted are still
  being decided.

## Options being considered

| License | Notes |
|---|---|
| Apache-2.0 | Permissive; explicit patent grant. Common for keyboards / IMEs. |
| MIT | Simplest permissive license; no explicit patent grant. |
| GPL-3.0 | Copyleft; would require derivatives to remain open source. |
| Proprietary | Keep closed source. |

## Third-party dependencies

Every third-party library included in this project must be recorded in
[`docs/third-party-licenses.md`](docs/third-party-licenses.md), regardless of
which license the project itself ultimately adopts.

## How to change this

Replace this file with the chosen license text (e.g. `LICENSE`) and update the
`## License` section in `README.md`.
